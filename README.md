# Stamplunch — Kontorets Lunchguide kring Stampgatan, Göteborg

Ett snabbt och roligt beslutsverktyg för kontoret kring Stampgatan, Odinsplatsen och Friggagatan i Göteborg.

## Funktioner
- **GPS & Kontorsläge**: Beräknar automatisk gångtid och avstånd från din enhets GPS-position eller kontoret på Stampgatan 20.
- **16 Utvalda Favoriter**: Jinx Empire, Bruk, Birria Seoul, Ullevi Thaikök, TomToms Burritos, ZenViet, Burgersson, Pylonen, m.fl.
- **Lunch-Roulette**: Lös beslutsångesten vid 11:30 med ett animerat slumpande lyckohjul med ljudeffekter och vibrationer.
- **Interaktiv Karta**: Leaflet-karta med mörkt tema som visar gångavstånd och restaurangnålar.
- **Slack-delning**: Kopiera färdigformaterade lunchförslag för teamets chattkanaler med ett enda klick.
